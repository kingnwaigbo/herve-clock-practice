HERVÉ CLOCK PRACTICE – PWA

Upload all files from this folder into the root of a GitHub repository.
In GitHub: Settings > Pages > Deploy from branch > main > /(root).
After publication, open the GitHub Pages URL in Chrome on Android and select Install app or Add to Home screen.
Load once online to enable offline caching.

To publish updates, change your files and increase CACHE_NAME in sw.js from v1 to v2, v3, etc.

This version bundles styling locally, with no network dependency.
